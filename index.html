05 / Workflow case studies

Three patterns, clearly scoped.

The CVs support AI output evaluation and data verification. The workflows below are reference designs to show how those principles could be applied—not claims of completed client deployments or measured outcomes.

REFERENCE DESIGN / A

Browser research pipeline

A bounded browser-assisted workflow for collecting information from approved public sources while keeping each result linked to where it came from.

  1. 1. Define the question, allowed domains and expected fields.
  2. 2. Gather only relevant page content and preserve source URLs.
  3. 3. Validate required fields and mark missing or conflicting evidence.
  4. 4. Present a compact evidence table for human review.

Controls: scope limits, source traceability, no bypassing access controls, visible failure states.

REFERENCE DESIGN / B

Structured web data checks

A script-assisted pattern for permitted data sources: normalize inputs, validate records and make data-quality exceptions easy to inspect.

  1. 1. Use an approved API or permitted source and respect its terms.
  2. 2. Parse into a documented schema with explicit data types.
  3. 3. Flag duplicates, missing values and unexpected formats.
  4. 4. Export validated records with a review and exception summary.

Controls: source permissions, rate limits, privacy minimization, deterministic validation.

REFERENCE DESIGN / C

LLM response evaluation

A review framework for comparing generated answers to task-specific criteria without presenting an uncalibrated score as accuracy.

  1. 1. Define criteria, source-of-truth material and error categories.
  2. 2. Review a representative sample against the same rubric.
  3. 3. Record evidence, severity, disagreement and adjudication.
  4. 4. Report sample size, confidence limits and known gaps.

Controls: reviewer calibration, documented rubric, adjudication, transparent denominator.

Evidence boundary: no client artifacts, public benchmark, source logs or case-study outcomes were supplied for publication. These designs are examples of a quality-first approach, not portfolio proof of a shipped system.
